管理本会话的定时提示。

请求：$ARGUMENTS

使用 `opencode` 命名空间中的 schedule 工具。它们只能看到本会话的定时任务。

- 要安排某事，调用 `schedule_create`。选择 `when`（`{ in: "20 minutes" }`、`{ at: "2026-10-27T09:00" }`、`{ every: "1 hour" }` 或 `{ cron: "0 9 * * 1-5" }`，可选配合 `until`，默认每 30 秒）。添加 `until`（唤醒一次后停止，默认 24 小时超时；如果条件已为真则立即匹配）或 `if`（为每个重复时段设置门控，不进行模型调用；创建时以不唤醒的方式记录 `state` 基线），使用 `{ run: "..." }` 做 shell 检查，或 `{ code: "..." }` 做 Code Mode JavaScript 检查，静态调用 `tools.<path>(...)`（不能用 `fetch`，限制 30 秒 / 20 次调用 / 32 KB），返回布尔值或 `{ wake, state?, message? }`。代码检查在创建时以 `state = null` 运行一次，若抛出异常则使 `schedule_create` 失败。要停止重复的定时任务，添加 `ends`：`{ after: "8 hours" }`、`{ at: "..." }` 或 `{ times: 3 }`。把 `prompt` 写成它唤醒时你将收到的指令，包含足够的上下文，让你无需本次对话也能行动。
- 要暂停、恢复或删除某个任务，先用 `schedule_list` 找到它的 id，然后调用 `schedule_pause`、`schedule_resume` 或 `schedule_delete`。
- 如果请求为空，调用 `schedule_list` 并展示本会话的定时任务：名称、时间、状态和下次运行时间。

用一行回复：改动了什么，下次何时触发。
